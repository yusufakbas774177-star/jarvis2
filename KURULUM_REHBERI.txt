================================================================
           J.A.R.V.I.S. WINDOWS ÇALIŞTIRMA VE HATA ÇÖZÜM REHBERİ
================================================================

İndirdiğiniz bu proje, modern bir tam kapsamlı (Full-Stack Express + React) 
J.A.R.V.I.S. Windows asistanı uygulamasıdır.

----------------------------------------------------------------
1. EN SIK KARŞILAŞILAN BAŞLAT.BAT SORUNLARI VE ÇÖZÜMLERİ
----------------------------------------------------------------

SORUN A: "Baslat.bat açılıyor ve hemen geri kapanıyor"
ÇÖZÜM:
1. İndirdiğiniz .ZIP dosyasını MUTLAKA klasöre çıkartın:
   - ZIP dosyasına sağ tıklayın -> "Tümünü Ayıkla" (Extract All).
   - ZIP'in içindeyken doğrudan Baslat.bat'a tıklarsanız Windows geçici 
     klasörde açtığı için dosyalar bulunamaz ve kapanır.
2. Bilgisayarınızda Node.js kurulu olmayabilir:
   - https://nodejs.org adresine gidin.
   - "LTS" yeşil butonunu indirip kurun. Kurulum bittikten sonra Baslat.bat'ı 
     tekrar açın.

SORUN B: "Port 3000 zaten kullanımda (EADDRINUSE)"
ÇÖZÜM:
- Yeni Baslat.bat bu durumu otomatik algılar ve eski açık kalan J.A.R.V.I.S. 
  oturumunu kapatır.
- Manuel kapatmak isterseniz: Görev Yöneticisi'ni (Ctrl+Shift+Esc) açıp 
  "Node.js: Server-side JavaScript" görevlerini sonlandırın.

SORUN C: "Tarayıcı açıldı ama 'Bu siteye ulaşılamıyor' diyor"
ÇÖZÜM:
- İlk açılışta paketlerin (node_modules) yüklenmesi bilgisayarınıza ve 
  internetinize bağlı olarak 1-2 dakika sürebilir.
- Siyah CMD konsol penceresini kapatmayın. "Server running on http://localhost:3000" 
  yazısını gördükten sonra sayfayı yenileyin (F5).

----------------------------------------------------------------
2. MANUEL ÇALIŞTIRMA (ALTERNATİF YÖNTEM)
----------------------------------------------------------------
Baslat.bat yerine komut satırından açmak isterseniz:
1. Proje klasörünün içine girin.
2. Klasörün üstündeki adres çubuğuna tıklayıp 'cmd' yazıp Enter'a basın.
3. Şu komutları sırayla çalıştırın:
   npm install
   npm run dev
4. Tarayıcınızda açın:
   http://localhost:3000

----------------------------------------------------------------
3. GEMINI YAPAY ZEKA ANAHTARI (İsteğe Bağlı)
----------------------------------------------------------------
J.A.R.V.I.S.'ın bulut yapay zeka beynini bağlamak için:
1. Proje klasöründeki ".env" dosyasını Not Defteri ile açın.
2. https://aistudio.google.com adresinden aldığınız ücretsiz API anahtarını ekleyin:
   GEMINI_API_KEY="AIzaSy..."

----------------------------------------------------------------
4. TAM MASAÜSTÜ UYGULAMASI (.EXE GİBİ) YAPMAK İÇİN
----------------------------------------------------------------
Uygulama tarayıcınızda (Chrome veya Microsoft Edge) açıkken:
1. Sağ üstteki üç noktaya (...) tıklayın.
2. "Uygulamalar" (Apps) -> "Bu siteyi uygulama olarak yükle" seçeneğine tıklayın.
Böylece J.A.R.V.I.S. bağımsız bir Windows programı gibi kendi penceresinde açılır!
